# Play Store Screenshot Guide

## Requirements
- Minimum 2 screenshots, maximum 8 per device type
- Size: 320px to 3840px, aspect ratio max 2:1
- Format: PNG or JPEG, 24-bit, no alpha

## Our Screenshots (1200x1920, Fire HD 10)

Upload these as **Tablet** screenshots:

| File | Screen | Description |
|------|--------|-------------|
| 01_home.png | Channels tab | Welcome screen with Add Playlist button |
| 02_favorites.png | Favorites tab | Favorites empty state with star icon |
| 03_guide.png | Guide tab | Guide empty state with clock icon |
| 04_settings.png | Settings tab | Full settings screen (Theme, EPG, About) |
| 03_add_playlist.png | Add Playlist dialog | M3U URL input dialog |
| 04_xtream.png | Xtream dialog | Xtream Codes login dialog |

## For Phone Screenshots
The same 1200x1920 images can also be uploaded as phone screenshots.
Google Play accepts them for both categories.

## Feature Graphic (required)
- Size: 1024 x 500 px
- Will be displayed at the top of the store listing
- Needs to be created separately (Canva, Figma, or similar)
- Suggested: Dark background (#1a1a2e), "FlowTV" text, tagline, channel grid mockup

## App Icon
- Size: 512 x 512 px
- Already generated as part of the adaptive icon setup
- Located at: android/app/src/main/res/mipmap-xxxhdpi/ic_launcher.png
