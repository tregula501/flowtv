## 3. Full Description (max 4000 characters)

```
FlowTV is a powerful, open-source IPTV media player designed for users who already have their own IPTV service or M3U playlists. Connect your existing playlists, and FlowTV gives you a polished, feature-rich viewing experience on Android.

IMPORTANT: FlowTV does not provide, host, or include any TV channels or streaming content. You must have your own IPTV subscription or playlist to use this app.

━━━━━━━━━━━━━━━━━━━━━━

PLAYLIST SUPPORT
Add your playlists and start watching in seconds:
 - M3U / M3U8 playlists via URL or local file
 - Xtream Codes API with secure login
 - Manage multiple playlists and switch between providers
 - Fast batch import with real-time progress tracking

TV GUIDE (EPG)
A full electronic program guide so you always know what's playing:
 - View current and upcoming programs at a glance
 - XMLTV-compatible guide with auto-refresh scheduling
 - Program progress indicators and detailed descriptions
 - Synced scrolling EPG grid for easy browsing

MULTI-VIEW
Watch up to 4 streams simultaneously on a single screen -- perfect for keeping an eye on multiple channels at once.

CHROMECAST & CASTING
Cast any stream to your Chromecast, Fire TV, or other Google Cast-compatible device. Automatic content detection ensures smooth playback on your big screen.

FAVORITES & ORGANIZATION
 - Star your most-watched channels for instant access
 - Browse channels by category and group
 - Full-text search across channels and programs
 - Swipe between channels during playback for quick switching

PRIVACY-FIRST DESIGN
 - No ads, no analytics, no tracking -- ever
 - No account creation required
 - Xtream credentials encrypted with Android Keystore
 - All data stays on your device
 - Open-source (GPL v3) -- verify the code yourself

PLAYBACK FEATURES
 - Adaptive HLS/RTMP streaming with auto-quality
 - Configurable buffer size and auto-retry on connection loss
 - Screen wake lock during playback
 - Stream recording on supported platforms (desktop)

CLEAN, MODERN INTERFACE
 - Dark and light themes to suit your environment
 - Material Design 3 with smooth animations
 - Intuitive navigation designed for touch

━━━━━━━━━━━━━━━━━━━━━━

FlowTV is a media player only. It does not include, distribute, or link to any streaming content or channel lists. Users are solely responsible for the content they access through their own IPTV services.

Source code: https://github.com/tregula501/flowtv
Privacy policy: https://github.com/tregula501/flowtv/blob/main/PRIVACY_POLICY.md
```

| Users can interact with each other | **No** | No social or communication features |
| Users can share their location | **No** | No location features |
| Users can purchase digital goods | **No** | No in-app purchases |
| Unrestricted internet access | **Yes** | The app connects to user-configured IPTV servers to stream media. It does not provide a general web browser. |

**Expected rating:** PEGI 3 / ESRB Everyone / IARC 3+

**Important note on "User-generated content":** Answer **No**. FlowTV does not host content, does not provide a content feed, and does not allow users to share content with one another. The user manually configures their own server addresses. This is analogous to a web browser or generic media player, not a UGC platform. If Google flags this during review, be prepared to explain that the app is a media player requiring user-supplied server credentials, similar to VLC or MX Player.
